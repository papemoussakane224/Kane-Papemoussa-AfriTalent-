# AfriTalent 🌍

**Projet web S2 — KANE Pape Moussa — L1 IAGE — ISI Institut Supérieur d'Informatique**

## Description
AfriTalent est une plateforme fictive de mise en relation entre freelances tech et entreprises africaines. Ce site vitrine présente la plateforme, ses fonctionnalités, ses tarifs et les profils de freelances disponibles.

## Technologies utilisées
- HTML5 sémantique
- CSS3 (Flexbox, Grid, Bento Grid, animations)
- Bootstrap 5
- JavaScript Vanilla
- Bootstrap Icons
- Google Fonts (Poppins + Playfair Display)
- Git & GitHub Pages

## Fonctionnalités principales
- Dark mode / Light mode avec localStorage
- Compteurs animés au scroll (IntersectionObserver)
- Filtrage dynamique des freelances par catégorie
- Validation du formulaire de contact côté client
- Navbar dynamique au scroll
- Bouton retour en haut
- Animations fade-in au scroll
- Design responsive (mobile, tablette, desktop)

## Pages
- `index.html` — Page d'accueil
- `freelances.html` — Catalogue des freelances
- `tarifs.html` — Plans tarifaires et FAQ
- `about.html` — À propos de l'équipe
- `contact.html` — Formulaire de contact
